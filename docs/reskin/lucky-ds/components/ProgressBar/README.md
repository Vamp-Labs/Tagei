# ProgressBar

The Bonus Level meter: a thick striped `lucky-bar` fill in a `bg-tile` track, with the next level number in `lucky` at the end.

- Provide: `value`, `max`, `next` (the level reached at max), `label` for assistive tech.
- Pair with a helper line above it ("2678 / 3000" in `ink`, "Until your next reward" in `ink-faint`).
