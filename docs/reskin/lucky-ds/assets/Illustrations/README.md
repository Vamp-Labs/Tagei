# Illustrations

Glossy 3D objects: one object per image, soft top-left light, no text baked in. Colored art means available or featured; silver art with a lock or chip means locked or Pro-only. `clover-mark` is the logo mark between LUCKY and GAMES; `coin` sits above the VP total.

These are crops from the reference screenshot at about 1x — placeholders until the original renders are added. Each crop keeps its original background (`bg-tile` for rewards, `hero-sky` for the hero, the room gradients), so place them on that surface.
