# SheetHeader

The top of a bottom sheet: a grabber, a back button, a centered title with a sub-line, and an optional trailing action such as the Pro badge.

- Provide: `title`, `subtitle`, `back` (true to show the back button) or `onBack`, `action` (a node, usually `Badge tone="pro"`).
- The sub-line is lowercase and states status ("status: basic").
