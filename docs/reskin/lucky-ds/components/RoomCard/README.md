# RoomCard

A multiplayer room in the "User's ROOMS" rail: illustration on top with the room name and player cap over it, seats and entry fee below, and the gold ring counter on the right.

- Provide: `art`, `title` (room name, e.g. Crash.Race), `maxPlayers`, `seats`, `entry` (in coins; a coin dot is appended), `count` (the ring number).
- Cards sit in a horizontal scroll rail on `lobby`, `space-3` apart, with the next card peeking.
